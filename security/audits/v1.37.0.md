# Gleam v1.37.0 security audit

## Scope

Diff: `306c135..1ce235d`.

Surface paths changed:

- `packages/runtime/src/handlers/wallet-lifecycle.ts`: the display settings record. `compactHeader` becomes `header` (`full`, `compact` or `minimal`), `showTokenLogos` becomes `tokenLogos` (on by default), and `tokenRows` (`detailed` or `simple`) is new. `setDisplaySettings` still checks every field's type and writes only the known fields. `loadDisplaySettings` upgrades older records and drops a malformed one to the defaults. The record holds view preferences only, and no key, session or signing path reads it.
- `packages/app/src/i18n/messages/settings-home.ts`, `onboarding.ts`: labels for the new settings, and one reworded onboarding sentence. No approval or recovery text changed.
- `apps/mobile/ios/App/App.xcodeproj/project.pbxproj`: version 1.37.0 and the build number incremented.

Other changes, outside the surface:

- Main screen: the focus view's top bar, the Header and Token rows settings, the minimal header's range and scope taps, and the chart range saved in `localStorage`.
- The Gleam Points row shows `GLM` letters in place of the Gleam mark while token logos are off.
- Versions: 1.37.0.

Run:

- `pnpm vitest run` (4138 passed), tsc on all eleven projects, eslint on changed files, `pnpm wxt:build`, `pnpm mobile:build`, `pnpm audit --prod`.
