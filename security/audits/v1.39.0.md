# Gleam v1.39.0 security audit

## Scope

Diff: `78a3d3b..3f76d33`.

Surface paths changed:

- `packages/runtime/src/create-runtime.ts`: the announcements handler gets the shell and version, read per fetch, so an entry can target `platforms` and versions `below` a bound. Malformed targeting drops the entry. The link allowlist and the credential-free GET are unchanged.
- `apps/extension/entrypoints/background/index.ts`: names its shell `extension`.
- `apps/mobile/src/worker/index.ts`, `apps/mobile/src/worker/platform.ts`: the worker takes its shell from its own name, which `app-platform.ts` sets from `Capacitor.getPlatform()`. Anything other than `android` or `ios` reads as `web`. A dApp has no way to name the worker.
- `apps/mobile/src/adapters/file-saver.ts`, `apps/mobile/android/app/src/main/res/xml/file_paths.xml`: exports are written to `cache/gleam-exports/`, and the `FileProvider` shares only that folder instead of the whole cache. Write, share, delete and the sweep of leftovers are otherwise unchanged.
- `apps/mobile/android/app/build.gradle`: release builds minify and shrink with R8. Capacitor plugins and SQLCipher keep their class names through their consumer rules.
- `packages/app/src/i18n/messages/send.ts`: one new message, shown when a failed send re-quotes a different fee.
- `packages/app/src/i18n/messages/onboarding.ts`: punctuation and wording in onboarding hints. No approval or recovery text changed.

Other changes, outside the surface:

- `SendView.tsx`: a failed send re-quotes the fee. If it changed, the review shows the new fee and waits for another tap. Nothing is signed with a fee the user hasn't seen.
- The wallet switcher shows watch-only as an inline label and hides "Make active" on phone.
- `security/audits/README.md` and `TEMPLATE.md`: the policy for handling findings. `docs/THREAT_MODEL.md` Known limitations now holds every accepted finding.
- Versions: 1.39.0.

Run:

- `pnpm vitest run`: 4205 passed, 5 skipped.
- tsc on all eleven projects, eslint, `pnpm wxt:build`, `pnpm mobile:build`, `pnpm audit --prod`.
- A minified release APK built, installed and launched on an emulator.

## Notes

No critical or high finding.

This is the first audit under the findings policy, so it no longer restates earlier audits' accepted findings.

Known limitations added: pending figures trust the shipped nodes; prices are display only; a dApp's L1 token transfer can lose its quote; translated errors match whole messages; Chinese translations are machine-written; the stored query cache is plaintext; an APK install can't update to the Play build; mobile link and dApp-view gaps; the Swift CodeQL job runs without `harden-runner`; Points and scans. These are the findings accepted from v1.27.0 to v1.38.0 that are still true.

Known limitations removed or never added, because they are fixed: the stale-fee retry (F-1), unminified Android release builds, the `FileProvider` sharing the whole cache, the Gradle wrapper checksum, Gemfile `CHECKSUMS`, the `assetlinks.json` fingerprints, and `release-app.sh` not checking `origin/master`.

Manual checks: a failed send that succeeds on retry in Chrome, unpacked. On Android, a minified release build: the wallet switcher, wallet create and unlock, key export through the share sheet, QR scan, biometric unlock and a dApp.
