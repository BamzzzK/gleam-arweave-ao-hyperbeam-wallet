# Gleam v1.44.0 security audit

## Scope

Diff: `82cc39e..8a416ee`. The release is mostly UI: borderless lists and inputs, a rebuilt Points screen, the wallet switcher switching in place, a popup/side-panel toggle, activity detail fixes (#170, #171, #173), the scan rounds by area (#174), and fixes for five low community advisories (F-1 to F-5).

Surface paths changed:

- `packages/app/src/approval/SigningApprovalScreen.tsx`, `packages/app/src/transfer-review/TransferReview.tsx`: the local `CopyIcon` moves to the shared `@gleam/ui` `copy-icons.tsx`, a static `currentColor` SVG. The approval preview's content and decoding are unchanged.
- `packages/app/src/screens/wallet-detail/src/WalletDetailView.tsx`: the same icon move, a borderless backup card, and a phone margin on the address. The keyfile export flow is unchanged.
- `packages/app/src/screens/onboarding/src/Import.tsx`, `ImportPhrase.tsx`: a fainter focus border only. Parsing, masking and the unknown-word warning are unchanged.
- `packages/app/src/screens/lock-settings/src/SecurityPhraseSection.tsx`: spacing only.
- `packages/app/src/i18n/messages/{main-screen,points,send,wallet-switcher}.ts`: copy changes and unused keys removed. Placeholders still match across languages (`catalog.i18n.test.ts`). No decoded data, address or tag value is translated.
- `packages/core/src/arweave/graphql.ts`: when a gateway returns the same transaction twice, a copy without a block no longer replaces a confirmed one. This changes only the activity status shown, not balances or signing.
- `packages/core/src/scan/{areas,challenge,index,rewards}.ts` and their tests: scan areas by surface tier, a preference for unexamined functions in the first challenge pick (still drawn from the seed), and the per-round reward step. No wallet code reaches these.
- `apps/extension/src/adapters/app-platform.ts` (with the new `side-panel.ts`): `sidePanel` becomes a port that opens the side panel from the popup (`sidePanel.open`) or the popup from the panel (`action.openPopup`), on a click. No permission is added. `packages/app/src/i18n/messages/settings-home.ts` gains its two labels.
- `packages/core/src/ao/peer-discovery.ts` (F-1): `normalizePeerUrl` rejects hosts ending in a dot and `.nip.io`, so `https://localhost./` can't be admitted as a public peer.
- `packages/runtime/src/create-runtime.ts` (F-2): a dApp `sign()`/`dispatch()` sending 1 of a process the token lookup reports as a collectible previews as that collectible, matching the hardware-wallet step. Any other quantity, or a failed lookup, keeps the token preview.
- `packages/app/src/transfer-review/{model.ts,DataItemCard.tsx}`, `packages/app/src/i18n/messages/approval.ts` (F-3): the unreadable item in a batch carries an "Unreadable transfer" label on its own card.
- `apps/mobile/plugins/dapp-view/android/.../DappWebView.kt` (F-4): the open-another-app prompt shortens only the link, so the target package always shows in full.
- `packages/app/src/screens/network-peers/src/NetworkPeersView.tsx` (F-5, outside the surface): peer rows show the full host and port and wrap instead of truncating.
- Tests next to each fix: `SigningApprovalScreen.approval.test.tsx`, `model.transfer-review.test.ts`, `index.dapp-view.test.ts`.

Outside the surface: `apps/points-api` scan rounds and migration `010_scan_areas.sql`, the site's scan pages, `scripts/scan`, `SCANS.md`, and the version bump.

Run:

- `pnpm vitest run`, tsc on all eleven projects, eslint, `pnpm wxt:build`, `pnpm mobile:build`, and a manual check in Chrome and on a phone.
