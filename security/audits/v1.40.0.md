# Gleam v1.40.0 security audit

## Scope

Diff: `3f76d33..062b2dc`.

Surface paths changed:

- `packages/runtime/src/handlers/approval.ts`, `packages/runtime/src/create-runtime.ts`: a grant keeps the site's icon and name for Connected apps. The icon is the dApp's `appInfo.logo`, else the favicon of an open tab on that exact origin, and passes `safeSiteIconUrl` (https or an image `data:` URL) before it is stored. The name is `appInfo.name`, already length-capped by the dispatcher, and is dropped if it holds control or bidi characters. `isValidGrant` accepts the two new fields only as string or null. Permissions, wallet binding and expiry are unchanged.
- `packages/app/src/approval/ConnectionRequestScreen.tsx`: `SCOPE_COPY` is exported for Connected apps to reuse. No change to what the approval shows.
- `packages/app/src/screens/lock-settings/src/BiometricSection.tsx`: a heading rule became spacing.
- `packages/app/src/i18n/`: eight new languages (ko, ja, es, pt-BR, tr, vi, ru, id), with the language list driving the catalog types and device-language matching. Every language carries every key with the same placeholders (`catalog.i18n.test.ts`). Decoded transaction data, addresses and tag values stay untranslated. Copy changes in lock, settings, send and main-screen messages.
- `apps/mobile/ios/App/App/Info.plist`: the new languages in `CFBundleLocalizations`.

Other changes, outside the surface:

- Connected apps shows each site's icon and name, with the hostname always under a dApp-chosen name.
- Settings home regrouped with a theme picker and an Appearance screen. Add a token moved into the token list's edit mode. Contacts can be edited from the send screen's saved list.
- The Send/Receive buttons and the anti-phishing word picker were English literals in `@gleam/ui`; they are now translated.
- Lock settings no longer shows the passkey's setup date. `createdAt` is still stored.
- Chrome `_locales` and iOS `InfoPlist.strings` for the new languages.
- `docs/THREAT_MODEL.md`: the machine-translation limitation covers every language.
- Versions: 1.40.0.

Run:

- `pnpm vitest run`: 4228 passed, 5 skipped.
- tsc on all eleven projects, eslint, `pnpm wxt:build`, `pnpm mobile:build`, `pnpm audit --prod`.
- The built extension loaded in Playwright, every popup screen and post-gate onboarding screen opened in all eleven languages, checked for clipped, off-screen, newly wrapped and untranslated text.
