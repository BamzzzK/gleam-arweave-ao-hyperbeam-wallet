# Gleam v1.36.0 security audit

## Scope

Diff: `d11d6f8..306c135`.

Surface paths changed:

- `packages/runtime/src/create-runtime.ts`, `handlers/approval.ts`, `handlers/transfer.ts`, `packages/core/src/arweave/transfer.ts`, `core/ao/l1-transfer.ts`, `core/ao/collectible-transfer.ts`, `packages/messaging/src/protocol.ts`: the fee the user sees is pinned as the transaction's reward for `sign`, `dispatch` and every L1 send. Before this, the preview and the builder each fetched a quote, so a lying gateway could show a low fee and have a higher one signed. Reported by Haven. A send whose fee isn't a whole number of Winston is refused. A dApp's L1 token transfer now quotes a fee in its preview, with a 10s budget.
- `packages/core/src/models/user-errors.ts` (new, added to the surface), `packages/core/src/{vault,keys,arweave,ao,hardware}`, `packages/runtime/src/handlers/*`: user-facing English moved into one table, thrown through `userErrorMessage`. String moves only. `packages/core/src/signer` is untouched; a test ties its copies to the table.
- `packages/app/src/i18n/` (new, added to the surface), `packages/app/src/approval/`, `packages/app/src/passkey/`, `packages/app/src/biometrics/`, `apps/extension/src/hardware/panels/`, `packages/keystone/src/KeystonePanel.tsx`: every approval string is translated into Simplified and Traditional Chinese. Errors are matched back to their code and translated at display by `errorText`. Decoded transaction data, addresses and tag values are never translated.
- `apps/extension/wxt.config.ts`: `description` is a localized message and `default_locale` is `en`. No permission or host change.
- `apps/mobile/ios/App/App.xcodeproj/project.pbxproj`, `Info.plist`: Chinese permission prompts; `CFBundleLocalizations`. Build numbers incremented.
- `packages/app/package.json`, `pnpm-lock.yaml`: new `flag-icons` 7.6.0 (MIT, no install scripts). Only three SVG files are imported, and no package code ships.
- `security/surface.txt`, `.github/CODEOWNERS`: the two new paths above.

Other changes, outside the surface:

- Language picker under Settings, with the choice in `localStorage`. All other screens are translated through `packages/app/src/i18n/messages/`.
- Versions: 1.36.0.

Run:

- `pnpm vitest run` (4127 passed), tsc on all eleven projects, eslint on changed files, `pnpm wxt:build`, `pnpm mobile:build`, `pnpm audit --prod`.
