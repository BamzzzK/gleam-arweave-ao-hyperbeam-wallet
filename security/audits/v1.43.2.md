# Gleam v1.43.2 security audit

## Scope

Diff: `7349f11..82cc39e`. v1.43.1's native projects still pointed at Capacitor 8.5.3 after #160 moved the packages to 8.6.0, so the app build regenerated them and refused the dirty tree. This release syncs them. The extension and the web bundle are unchanged from v1.43.1, so this release replaces it before any store upload.

Surface paths changed:

- `apps/mobile/ios/App/CapApp-SPM/Package.swift`, `apps/mobile/android/capacitor.settings.gradle`: `cap sync` output. Each plugin path moves from its `@capacitor+core@8.5.3` directory to the `8.6.0` one, and `capacitor-swift-pm` from 8.5.3 to 8.6.0. No plugin is added or removed.
- `apps/mobile/ios/App/App.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved`: `capacitor-swift-pm` resolves to 8.6.0 (`e9e932f`), the tag Capacitor publishes for that release. No other package changed.

Outside the surface: `security/scan/SKILL.md` and `SCANS.md` (#167) ask for a missing attestation id before filing and during triage. `apps/mobile/native-sync.mobile.test.ts` fails when the native projects don't match the installed `@capacitor/core`.

Run:

- `pnpm vitest run`, tsc on all eleven projects, eslint, `pnpm wxt:build`, `pnpm mobile:build`.
